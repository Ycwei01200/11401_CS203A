# Tree (樹)
***
## About Tree

- **What is a Tree?**
    * It is a non-linear hierarchical **data structure**.
- **Where are trees used?**
    * Computer **file systems**.
    * **Family Trees**.
- **What types of trees are there?**
    * There are several types of **trees**.
    * For Example:
      `Binary Tree`, `Binary Search Tree (BST)`, `Balanced Tree`.
- **the difference between height and depth?**
  - **Height**: Count edges from **root → deepest leaf**. (The tree's total floors)
  - **Depth**: Count edges from **root → this node**. (Which floor this node is on)    
## Tree's Composition
    
| 🌲 Term               | 💡 Definition                                                                                                             |
| :------------------- | :----------------------------------------------------------------------------------------------------------------------- |
| **Sibling**          | Nodes that share the same parent node.                                                                                   |
| **Parent / Child**   | The **Parent** is a node directly connected to the next level; the **Child** is a node directly connected to its parent. |
| **Degree (Fan out)** | The number of children a specific node has.                                                                              |
| **Root**             | The topmost node of the tree. It has no parent.                                                                          |
| **Leaf**             | A node that does not have any children. Also called an External Node.                                                    |
| **Edge**             | The connection or link between two nodes in the tree.                                                                    |

## Tree's Traversal
- **DFT (Depth-First Traversal):**
    * A **traversal method** that follows the `Depth-First` strategy.
    * There are three types of DFT:
        * **A (Postorder):** `Left-Right-Root`. It is used for **deletion** and **freeing** memory.
        * **B (Preorder):** `Root-Left-Right`. It is used to **copy** data.
        * **C (Inorder):** `Left-Root-Right`. It is used for **sorting**.
- **BFT (Breadth-First Traversal):**
    * A **traversal method** that visits nodes level by level using a queue.

## Types of Trees
-   **Binary Tree:**
    * **Def:** A hierarchical data structure in which each node has at most two children.
    * **Characteristic:**
        * Each node has at most two children (0, 1, or 2).
    * **types**:
        ![https://github.com/Ycwei01200/11401_CS203A/blob/main/Picture/types_of_binary_tree.png?raw=true](https://github.com/Ycwei01200/11401_CS203A/blob/main/Picture/types_of_binary_tree.png?raw=true)
        
        resource from: [medium](https://medium.com/data-science/5-types-of-binary-tree-with-cool-illustrations-9b335c430254)

        * Full Binary Tree: every node has 0 or 2 children.
        * Complete Binary Tree: All levels have filled with nodes except the last level,all the nodes are as left side as possible.
        * Perfect Binary Tree:All internal nodes have 2 children ,and all the leaf nodes have the same depth.
        * Degenerate Binary Tree:Every parent node has only one child node.

        
-   **Binary Search Tree (BST):**
    * **Def:** A tree that inherits from `Binary Tree`, has at most two children, and follows:
        $$\text{Left Node} < \text{Parent} < \text{Right Node}$$
    * **Characteristic:**
        * All nodes in **the** left **subtree have values** less than the node's value.
        * All nodes in **the** right **subtree have values** greater than the node's value.
        * The rule applies recursively **to** all subtrees.

-   **Balanced Tree:**
    * **Def:** A Balanced tree ensures **the height difference** between subtrees is **minimized**.
    * **Why?**
        * If the tree is not **balanced**, it **can** become too deep, causing **poor** time complexity.
         $$O(\log n) \to O(n)$$
