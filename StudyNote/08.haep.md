# Heap Data Structure Notes

## 1. About Heap (核心概念)
---
* **What's Heap?**
    * It's a **complete binary tree** that satisfies the **Heap-Order property**.
* **Complete Binary Tree (結構特性):**
    * All levels of the tree are filled with nodes except the last level. Also, nodes are inserted from left to right sequentially.
* **What's `Heap-Order` meaning? (排序特性):**
    * **Definition:** The **Heap-Order property** is not the order in which elements are inserted; it is a **magnitude relationship rule** that must always be maintained between a parent node and its child nodes.
    * **`Max-heap`:** The maximum element is always at the root. Each parent is greater than its children.
    $Parent\ Nodes \ge Child\ Nodes$
    * **`Min-heap`:** The minimum element is always at the root. Each parent is less than its children. 
    $Parent\ Nodes \le Child\ Nodes$

## 3. ADT/Time-Complexity (抽象資料型態與時間複雜度)
---
| Operation | Description | Time Complexity |
| :--- | :--- | :--- |
| **Access** | Accessing by index | $O(1)$ |
| **Search** | Searching for an arbitrary value | $O(N)$ |
| **Insertion** | Add new element and restore heap-order | $O(\log N)$ |
| **Deletion** | Remove a node and restore the heap property | $O(\log N)$ |
| **Extract\_root** | Remove the maximum/minimum element | $O(\log N)$ |
| **Peek\_root** | Access the maximum/minimum element | $O(1)$ |
| **build\_heap** | Convert array to heap | $O(N)$ |
| **heapify** | Restore the heap property at node i | $O(\log N)$ |

* **Insertion 解釋:**
    因為節點在樹狀資料結構的成長速度是 $2^N$ ，反過來說我們可以將樹的高度記為 $\log(N)$ ，假設插入最小的節點在`Min-Heap`的最下方，那也代表要恢復`Heap`的性質只要 $O(\log N)$。
