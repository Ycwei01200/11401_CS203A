# Stack(堆疊)

***

## What is *Stack*?
*    ### What?
        - It's a linear data Structure which follows the LIFO(Last-In-First-Out) principle.
*    ### Where?
        - REDO/UNDO function
        - Model Stack
*    ### How?
        - Stack(Array-Based)
        - Stack(Linked-list-based)
## How to implement Stack with different data type?
*   ### Stack(Array-based)
    - `initialize`
        ```c
            int the_Array_num = 10;
            int arr[the_Array_num];
            //Static Array as for the example
        ```
    - `Push`
        ```c
            int top = the_Array_num ;
            int insert_value;
            if(cin>>insert_value && top < the_Array_num){
                arr[top++] = value;
            }
        ```
    - `Pop`
        ```c
            int top = the_Array_num;
            int value;
            if(top!=0){
                value=arr[top--];
            }
        ```
    - `Edge Case`
        1. You should check if there are any `overflow` or `underflow` conditions happen.
        (Such as `top == the_Array_num-1` or `top == -1`)
        2. Resizing array must be reallocated a array to store the data.(if you are using the static array)
