# Graph

## 1. About Graph

### What's Graph?
- A collection of vertices (nodes) which are connected by edges to represent the **relation** between them.

### Component of Graph
- **Vertex**: The nodes in the graph.
- **Edge**: The relations between vertices.
  - Undirected edge: The edge has no direction.
  - Directed edge: The edge has direction.
  - Weighted edge: The edge has weight.
  - Directed and Weighted edge: The edge has direction and weight.
  - Label edge: The edge has label.

### Degree of Vertex
- **Definition**: The degree of a vertex is the number of edges which are related to the vertex.
- **In-degree**: The number of edges which point to the vertex.
- **Out-degree**: The number of edges which point from the vertex.

## 2. Graph Representation

### Adjacency Matrix
- **Definition**: A matrix which shows the relation between vertices.
- **Pros**:
  - Easy to check whether two vertices are connected.
  - Easy to implement.
  - Best for dense graph (several edges per vertex).
  - The time complexity of lookup is $O(1)$.
- **Cons**:
  - Use too much space (if you have n vertices, you need $n^2$ space to store the matrix) $\rightarrow$ $O(n^2)$.
  - Not best for sparse graph (most of the edges are not connected).
  - Getting neighbors of a vertex needs to traverse the whole row of the matrix $\rightarrow$ $O(n)$.
  - Harder to dynamically insert or delete edges (Rebuild the matrix).
- **Best for**:
  - Dense graph.
  - Graph which needs fast lookup.

### Adjacency List
- **Definition**: A list which shows the relation between vertices.
- **Pros**:
  - Use less space, only store the edges which are related to the vertex $\rightarrow$ $O(V + E)$.
  - Best for sparse graph (the number of vertices is greater than the number of edges).
  - Inserting or deleting an edge is $O(1)$.
  - Easy to scale to large graph (millions of vertices).
  - Best for `BFS` or `DFS` $\rightarrow$ $O(V + E)$.
- **Cons**:
  - Harder to implement (`pointer` + `nodes`).
  - Checking whether two vertices are connected needs $O(deg(V))$.
  - Slightly memory overhead (several linked list implementation).
- **Best for**:
  - Sparse graph.
  - BFS or DFS.
  - Dynamic graph.

## 3. The Comparison of Adjacency Matrix and Adjacency List

| Aspect                      | Adjacency Matrix                                                    | Adjacency List              |
| --------------------------- | ------------------------------------------------------------------- | --------------------------- |
| **Space Usage**             | $O(V^2)$                                                            | $O(V + E)$                  |
| **Lookup Time**             | $O(1)$                                                              | $O(deg(V))$                 |
| **Insertion/Deletion Time** | Not easy to dynamically insert or delete edges (Rebuild the matrix) | $O(1)$                      |
| **Traverse for DFS/BFS**    | $O(V^2)$                                                            | $O(V + E)$                  |
| **Implementation**          | Easy                                                                | Hard (`pointer` + `nodes`)  |
| **Best for**                | Dense graph, Graph which needs fast lookup                          | Sparse graph, Dynamic graph |

## 4. ADT of Graph

- `Graph create()`: Create a new graph.
- `Graph insert_vertex(Graph, v1)`: Insert a vertex into the graph.
- `Graph insert_edge(Graph, v1, v2)`: Insert an edge which connects v1 and v2 into the graph.
- `Graph remove_vertex(Graph, v1)`: Remove a vertex from the graph.
- `Graph remove_edge(Graph, v1, v2)`: Remove an edge which connects v1 and v2 from the graph.
- `Bool Isempty(Graph)`: Check whether the graph is empty.
