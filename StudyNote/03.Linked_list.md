##  關於 Linked List (基礎概念)

* ### Linked List 是甚麼 (What)?
    - 是一種能夠把每樣東西，用鏈結的方式連接起來的資料結構。
    - 整個 Linked List 一定會有一個**head**（頭部）跟**tail**（尾部）。

* ### Linked List 何時用 (When)?
    - 當你比較頻繁地進行**插入**或**刪除**資料時，就適合使用。

* ### Linked List 為何用 (Why)?
    - 插入/刪除資料的時間複雜度低 ($O(1)$)，因為不需要移動大量連續的元素。

* ### Linked List 在哪裡用 (Where)?
    - To-do list / Check list / 資料結構 (Data Structure) 的基礎實作。

* ### Linked List 的種類
    - **Singular Linked List** (單向鏈結結構)
    - **Doubly Linked List** (雙向鏈結結構)
    - **Circular Linked List** (循環鏈結結構)

---
## 記憶不連續性?
    - Array (contineuous access): 連續地資料存儲空間，可分為**static** / **dynamic** array。
    - Linked List(sequencial access):不連續地資料存儲空間，需事先分配空間(always dynamic)。


## 種類詳解 (Types)

* ### Singular Linked List (單向)
    - 只有單一方向，每組節點只存放一個指向**下一個節點**的指標。
    
    ![Singular Linked List 示意圖:Created by Gemini](https://github.com/Ycwei01200/11401_CS203A/blob/main/Picture/Singular_Linked_list.png?raw=true)
    -Singular Linked List 示意圖:Created by Gemini

* ### Doubly Linked List (雙向)
    - 具有兩個方向，每個節點存放一個指向**前方**（Prev）與一個指向**後方**（Next）的指標。
    ![Doubly Linked List Node](https://www.alphacodingskills.com/imgfiles/doubly-linked-list-node.PNG)
     [Resource](https://www.alphacodingskills.com/ds/circular-doubly-linked-list.php)


* ### Circular Linked List (循環)
    - 細分為 Singular / Doubly Circular Linked List。
    - **Singular Circular Linked List:** 只有單一方向，但 **Tail** 後方接著 **Head**。
    - **Doubly Circular Linked List:** 具有兩個方向，且 **Tail** 後方接著 **Head**。

## 🛠️ Linked List 的實作與操作 (C++)

* ### Linked List 在 C++ 通常以 `struct` 來實作 (Node 定義)

    ```c++
    #include <iostream>

    struct Node {
    	int value;  // 每一個節點的資料
    	Node* next; // 指向下一個節點
    }; // 結構定義結尾需要分號

    int main() {
    	// 宣告有一個新的節點
    	Node* head = new Node(); 
    	head->value = 1; // 存放節點的資料 (注意: 變數名已修正為 value)

    	// 實作結束後需要釋放記憶體
    	delete head;
    	return 0;
    }
    ```

* ### 插入 (Insertion)

    * #### 插入在開頭
        ```c++
        void insertion_in_head(node*& head,int val){
        	node* new_head  = new node(); //建造一個新的節點
        	new_head->value = val; //並進行存值
        	new_head->next  = head; //連接原本的節點(head)
        	head            = new_head; //把新的節點連接
        }
        ```
    
    * #### 插入在中間
        ```c++
        void insertion_in_middle(node*& head, int goal, int val){
        node* prev = head;
         
        // 找到 goal 前一個節點
        while(prev->next->value != goal){
        	prev = prev->next;
        }

        node* insert_node = new node();
        insert_node->value = val;
        insert_node->next = prev->next;
        prev->next = insert_node;
        }

        ```
    
    * #### 插入在後面
        ```c++
        void insertion_in_tail(node*& head,int val){
        	node* current = head;
        	node* new_tail= new node(); 
        	new_tail->value = val;new_tail->next = NULL;
        	while(current->next != NULL){
        		current = current -> next;
        	}
        	current->next = new_tail;
        	 
        	 
        }
        ```
*   ### 刪除 (Deletion)
    * 以下程式碼會是閹割版，因為是針對不同情況預設出來的程式碼，會列出完整版
    * #### 刪除在開頭(`head`)
        ```c++
        void delete_in_head(node*& head){
        if(head == NULL) return;
        node* temp = head;//暫存舊的指標
        head = head->next;//確保鏈結成功
        delete temp;//刪除指標
        }
        ```
    * #### 刪除在中間
        ```c++
        void delete_in_middle(node*& head, int val){
        if(head == NULL) return;
        node* current = head;
        while(current->next != NULL && current->next->value != val){//Traverse
            current = current -> next;
        }
        node* temp = current->next;//暫存舊的指標
        current->next = current->next->next;
        delete temp;//刪除指標
        }
        ```
    * #### 刪除在尾部(`tail`)
        ```c++
        void delete_in_tail(node*& head){
        if(head == NULL) return;//edge cases

        if(head->next == NULL){ //只有一個節點的情況
            delete head;
            head = NULL;
            return;
        }
        node* current = head;

        while(current->next->next != NULL){//Traverse
            current = current->next;
        }
        node* temp = current->next; // 鎖定最後一個節點
        current->next = NULL;       // 斷開連結
        delete temp;
        }
        ```
*   ### Swap by node operation(Poniter manipulation)

        ``` c++
        void swap_by_node(node* head,int form_val,int to_val){
        if(head == NULL) return;
        node* prev_form = head;
        node* current1  = head;
        node* prev_to   = head;
        node* current2  = head;
        while(prev_form->next != NULL && prev_form->next->value != form_val){
            prev_form = prev_form->next;
        }
        current1  = prev_form->next;
        while(prev_to->next != NULL && prev_to->next->value != to_val){
            prev_to = prev_to->next;
        }
        current2  = prev_to->next;
        
        prev_form->next = prev_form->next->next;
        current1->next  = NULL;

        prev_to->next   = prev_to->next->next;
        current2->next  = NULL;

        
        current1->next = prev_to->next;
        prev_to->next  = current1;

        current2->next = prev_form->next;
        prev_form->next= current2;
        }

        ```

    ### Selection Sort(Linked List)

        ```c++
        //by pointer
        void Selection_sort_by_pointer(node*& head){
        // 1. 基本檢查：如果是空串列或只有一個節點，不用排
            if(head == NULL || head->next == NULL) return;

            // i 是「目前要處理的位置」
            for(node* i = head; i->next != NULL; i = i->next){
            
            // --- 步驟 A: 找出最小值 ---
            node* min_node = i;       // 先假設 i 自己是最小的
            node* prev_min = NULL;    // 紀錄 min_node 的前一個節點 (為了拔出來用)
            
            node* prev_j = i;         // 這是 j 的前一個節點
            for(node* j = i->next; j != NULL; j = j->next){
                if(j->value < min_node->value){
                    min_node = j;
                    prev_min = prev_j; // 記住最小值的前一個是誰
                }
                prev_j = j; // 往下走
            }

            // --- 步驟 B: 如果真的找到比 i 更小的節點，就進行搬移 ---
            if(min_node != i){
                
                // 1. 【拔出來】把 min_node 從原本位置移除
                // prev_min->next 接到 min_node->next，這樣 min_node 就斷開了
                prev_min->next = min_node->next;

                // 2. 【插進去】把 min_node 插到 i 的前面
                min_node->next = i;

                // 3. 【接起來】處理 i 的前一個節點指向 min_node
                if(i == head){
                    head = min_node; // 如果 i 是頭，頭就要換人做
                } else {
                    // 如果 i 不是頭，我們要找到 i 的前一個節點 (prev_i)
                    node* prev_i = head;
                    while(prev_i->next != i){
                        prev_i = prev_i->next;
                    }
                    prev_i->next = min_node; // 讓前一個節點指向新的 min_node
                }

                // 4. 【更新 i】
                // 因為我們把 min_node 插到了 i 的位置，
                // 現在 i 指標應該要指著這個新位置 (min_node)，
                // 這樣迴圈的 i = i->next 才會正確走到下一個位置 (原本的 i)。
                i = min_node;
                    }
                }
            }   
        ```
        

        ```c++
            // by value
            void Selection_sort_by_value(node* head){
                if(head == NULL || head->next == NULL) return;
                for(node* i = head; i != NULL ; i = i->next){
                    node* min_node = i;
                    for(node* j = i->next; j != NULL; j = j->next){
                        if(j->value < min_node->value){
                            min_node = j;
                        }
                    }
                    if(min_node != i){
                        int temp = i->value;
                        i->value = min_node->value;
                        min_node->value = temp;
                    }
                }
            }
        ```
