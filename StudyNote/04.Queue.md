# Queue
***
## About Queue?
    ### What is Queue?
        * A linear data Structure that follos `FIFO`(First-In-First-Out) rule.
    ### Where to use Queue?
        * Task scheduling / suffering(I/O)
    ### How to implement Queue?
        * Array / Linked List
## Implementation(Queue)
    ### Array-based Queue
        * Requirment variable: Front, Rear, Array Size, Current
        * Operation:
            * Enqueue : $Array[  (rear + 1) % array_size] = value$
            * Dequeue : $Array[  (front + 1) % array_size] = value$
        * Edge Case:
            * When the queue is full, and we try to enqueue a new element, we need to check if the enqueue operation which causes overflow.
            ```c
                if((rear + 1) % array_size == front){
                    return ;
                }
            ```
            * When the queue is empty, and we try to dequeue a new element, we need to check if the dequeue operation which causes underflow.
            ```c
                if(front == rear){
                    return ;
                }
            ```
    ### Linked List-based Queue
        * Requirment variable: front, rear
        * initialization:
            ```c
                //先宣告一個 Linked List 陣列
                front = head; //使front 和 rear 都指向同一個位置
                rear =  head;
            ```

        * Operation:
            * Enqueue : 
                rear->next->val = value; rear = rear->next;
            * Dequeue :
                front = front->next;
