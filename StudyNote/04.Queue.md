# Queue

---

## About Queue

### What is Queue?
* A linear data structure that follows `FIFO` (First-In-First-Out) rule.

### Where to use Queue?
* Task scheduling / buffering (I/O)

### How to implement Queue?
* Array / Linked List

---

## Implementation

### Array-based Queue

**Required variables:**
* Front, Rear, Array Size, Current

**Operations:**
* **Enqueue:** `Array[(rear + 1) % array_size] = value`
* **Dequeue:** `Array[(front + 1) % array_size] = value`

**Edge Cases:**

* **Queue Full (Overflow):** When the queue is full and we try to enqueue a new element:
    ```c
    if ((rear + 1) % array_size == front) {
        return;
    }
    ```

* **Queue Empty (Underflow):** When the queue is empty and we try to dequeue an element:
    ```c
    if (front == rear) {
        return;
    }
    ```

### Linked List-based Queue

**Required variables:**
* front, rear

**Initialization:**
```c
// 先宣告一個 Linked List
front = head; // 使 front 和 rear 都指向同一個位置
rear = head;
```

**Operations:**
* **Enqueue:** 
    ```c
    rear->next = newnode;
    rear = rear->next;
    ```
* **Dequeue:**
    ```c
    if (front->next != NULL) {
        front = front->next;
    }
    ```

## ADT (Abstract Data Type)

* `isFullQ(queue, max_queue_size)`: Check whether the queue is full
* `addQ(queue, element)`: Insert an element into the queue
* `deleteQ(queue)`: Delete an element from the queue
